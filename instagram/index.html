Instagram: cua de publicacions

Com funciona. Res no es publica fins que no ho aproves. Per aprovar una publicació, a data/instagram.json canvia "approved": false per "approved": true (també pots canviar el text, la data o l'ordre de les imatges) i desa el canvi a GitHub.

Un cop a Netlify hi ha la variable IG_ACCESS_TOKEN, cada hora es comprova si hi ha alguna publicació aprovada que toqui i se'n publica una. Si una publicació aprovada fa més de 48 hores que havia de sortir, no es publica: posa-li una data nova.
